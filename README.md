One emoji that stands for an AI agent, for make.fun's 'Your Agent in One Emoji' bounty.

## The pick

🧞 **Genie.** An agent is a helper that acts on your behalf: you state a wish, it does the work out of sight, and the result appears. The genie is that archetype in one glyph — a servant who grants wishes — which is how an agent behaves, not just what it is. It reads instantly at small size, stays far from the obvious robot face or smiley, and its playful tone fits an agent that delights by doing the work for you.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22, stdlib only, deterministic) writes the single glyph to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) — exactly 1 character, 4 bytes of UTF-8, inside the gate's 1–16 characters.
